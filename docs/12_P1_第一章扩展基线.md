# P1 第一章扩展基线｜修仙御兽：万剑封妖

> 文档状态：**生效**
> 阶段：**P1.1｜第一章内容扩展首个迭代**
> 最后更新：**2026 年 9 月 11 日**
> 前置版本：P0 第一章单局战斗闭环，回档点 `c3de15d`。
> 本文优先级：P1 客户端开发以本文为准；P0 已生效规则仍由 `01_P0_产品与开发基线.md` 保留并作为稳定基线。

## 1. P1.1 目标

将当前“单局守线 + 章节 Boss”的 P0 原型，扩展为可连续推进的**第一章前段内容闭环**：

```text
进入章节 → 选择普通关 → 守线战斗 → 获得材料/基础装备 → 查看并穿戴 → 解锁下一关 → 进入章节 Boss
```

P1.1 先建立第一章的推图、奖励、装备和剧情引导骨架。寻木青雀首次结契继续作为阶段目标，不改变其“首次必定成功”的既定规则。

## 2. P1.1 本轮范围（生效）

### 2.1 客户端内容

1. **章节关卡推进**
   - 首页改为第一章关卡地图，显示关卡解锁、当前进度、推荐战力与首次奖励。
   - 首批落地 3 个普通关：`1-01 荒原警兆`、`1-02 残阵回响`、`1-03 剑痕拾遗`。
   - 关卡依次解锁、通关后保存进度、已完成关卡允许重复挑战。
   - 现有寻木青雀 Boss 战作为后续锁定节点保留，不能被 P1.1 改坏。

2. **普通关战斗配置化**
   - 复用已验证的下半屏移动、自动御剑、守线、越线扣护阵 HP、掉落磁吸与结算能力。
   - 仅通过波次、妖物组合、生命、移动速度、奖励和背景文本区分；不加入复杂躲技能或多角色战斗。
   - 普通关不提供抓捕入口；抓捕仅在章节 Boss 中出现。

3. **基础装备与材料闭环**
   - 新增固定属性基础装备：荒原护腕、守阵法衣、温灵玉佩；不加入随机词条、套装、锻造或交易。
   - 普通关首通按固定配置产出装备或材料；重复通关以仙石、剑胚残铁等基础收益为主。
   - 新增背包查看、穿戴/卸下与固定属性生效；变化必须反映在战力或实战属性中。

4. **轻量任务与剧情引导**
   - 关卡进入前、首次通关后展示短对白/任务提示，使用裴观岳、叶轻舟和万剑真君的已确认身份与语气。
   - 只服务于守线、掉落、装备的首次理解；不做长过场、配音、立绘生产或分支剧情。

### 2.2 存档与兼容

- 继续使用浏览器 `localStorage`；新增字段必须能从 `wanjian_fengyao_p0_v3` 的既有存档平滑迁移。
- 已拥有寻木青雀、飞剑等级、仙石、镇妖葫芦、法器展示和首次结契完成标记均不得丢失。
- 每个新增字段必须有默认值、迁移逻辑和回归用例。

## 3. 本轮明确不做

- 第一章剩余 5 个普通关、精英 Boss、完整章节结算与第二章；
- 御兽实际出战、切换、主动技能、成长、羁绊；
- 多次虚弱、逃跑、碎片、复杂 Boss 两阶段规则；
- 装备强化、随机词条、打造、分解、交易、商城；
- MySQL、账号、服务端结算、抖音小游戏 SDK、支付与运营系统；
- 多角色、公会、排行榜、活动、体力或门票体系。

## 4. P1.1 验收标准

1. 新存档可从 `1-01` 开始，完成普通关后正确解锁下一关；刷新页面后进度仍存在。
2. 旧 P0 存档打开后不会丢失仙石、飞剑、寻木青雀和首次结契状态。
3. 三个普通关均可进入、完成、失败并重试；守线、自动攻击、暂停、移动、掉落吸附不回退。
4. 首通奖励只领取一次；重复挑战按配置发放，不发生无限领取首通装备。
5. 基础装备可在法宝页查看并穿戴；穿戴前后属性与实战伤害/护阵效果一致。
6. 抓捕与存档自动回归检查继续全部通过；当前共 19 项，包含 P0 首次结契规则与 P1 旧存档迁移。
7. 每项开发同步总览、P1 回归清单、交接日志和 Git 回档点。

## 5. 实施顺序

1. 建立关卡、奖励、装备的静态配置与旧存档迁移骨架。
2. 实现章节地图、关卡选择、锁定状态与普通关结算/解锁。
3. 实现基础掉落、背包、穿戴及属性结算。
4. 补充首次任务对白和装备引导。
5. 新增 P1 自动回归检查，完成全流程验收后，再评估 `1-04 守山灵识` 与御兽出战功能。

## 6. 主题与体验红线

- 保持国风修仙、天衍剑宗、万剑镇妖与净化结契主题；不得替换为西幻、卡牌抽取或机械捕捉表达。
- 万剑真君仍是唯一可操作角色；普通关以低操作门槛的自动御剑守线为主。
- 第一章 NPC 只承担必要引导：裴观岳负责宗门危机，叶轻舟负责掉落与装备，玄曜仅在后续结契节点出现。
- 所有数值和奖励服务于“推图—产出—装备—再推图”，不加入体力或强制等待。
