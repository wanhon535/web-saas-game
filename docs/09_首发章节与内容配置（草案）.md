## 1. 首发规模（已确认）

| 内容 | 首发目标 |
|---|---:|
| 主线大章节 | 6 章 |
| 普通关卡 | 每章 8–10 个，合计约 48–60 个 |

**内容生产原则**：首发优先保证 6 章主线、12 个差异化 Boss、装备/御兽成长和资源循环完整；困难版、活动 Boss 与特殊刷新 Boss 使用现有地区、Boss 和机制扩展，不在首发堆砌无关副本。

## 2. 主线总纲（已确认方向）

万剑真君是失忆的上古封妖传人，也是上古镇妖宗门“天衍剑宗”的末代宗主。该宗门曾极为强大，却在长期对抗上古妖物的战争中逐渐衰败并最终隐世。妖界裂隙松动后，健康灵兽会被污染而失控，更强悍的裂隙妖物也会进入现世；两类 Boss 都能在主角实力足够时被驯服。万剑真君在镇守残存宗门、追查妖潮源头、收服妖兽的过程中，逐渐恢复封妖记忆，并发现宗门衰败与妖界裂隙之间的深层关联。

首发终局需要同时完成：

1. 击败终局妖王或其核心化身；
2. 暂时稳定或重新封印妖界裂隙；
3. 揭示万剑真君、宗门与妖界的关键关联；
4. 留下新的裂隙、失落封印或妖族势力，承接后续版本。

## 4. 章节内关卡模板

每章按 8–10 个普通关、1–2 个精英 Boss 关、1 个章节终局 Boss 关设计；以下为每章至少包含的推荐结构：

```text
1. 章节开场与新地图教学
2. 基础妖潮与新妖物
3. 强化妖潮 / 掉落目标
4. 首次引入章节机制
5. 精英前置关
6. 精英 Boss（可抓御兽候选）
7. 剧情推进与机制强化
8. 章节高压妖潮
9. 终局前置关（可选）
10. 章节终局 Boss（可抓御兽候选）
```

## 5. 首发 Boss 与御兽分配建议

- 每章配置 1–2 名精英 Boss 与 1 名终局 Boss，合计 12–18 个主要 Boss；其中首发主要可抓御兽数量控制在 6–12 只。
- 每个 Boss 都拥有独立的抓捕阈值、虚弱次数、失败状态、逃跑概率、击杀碎片和第二阶段奖励配置。
- 常规 Boss：默认 2–3 次虚弱窗口；困难版本可增加阶段技能、回血、逃跑与移动压力。
- 御兽的第一批差异化定位建议覆盖：护盾、防守、单体爆发、范围清怪、减速控制、增伤、治疗/续航、资源增益等方向。

## 6. 首发制作顺序（不等于当前 P0 排期）

1. 完成当前 P0 的完整试玩验收和稳定修复。
2. 锁定世界观命名、六章故事细纲、12 个 Boss 与首批御兽定位。
3. 建立正式版的 MySQL 数据模型、账号/存档、配置和战斗结算底座。
4. 先量产第一、二章的正式版内容，验证“推图—抓宠—装备—养成—再推图”长期循环。
5. 依次量产第三至六章、资源副本、任务、交易、活动与上线能力。
6. 完成移动端/抖音适配、经济校验、交易安全、性能和发布测试。

## 7. 已确认的世界观补充

1. 主角所属宗门原本极为强大，在长期对抗上古妖物后逐渐衰败并最终隐世；万剑真君为该宗门末代宗主。宗门正式名称确定为“天衍剑宗”；隐世后仍有少数长老、弟子与守宗力量留存，同时存在失散或沉睡成员，他们将担任角色、主线和支线引导。
2. 后续版本可开放“创建宗门”玩法；不提前纳入 P0 或首发核心内容。
3. Boss 同时包含被裂隙污染的健康妖兽/灵兽与更强悍的裂隙妖物；主角实力足够时，所有 Boss 都具备被驯服的可能，难度按 Boss 强度递增。
4. 六章地域递进结构已确认采用；各章具体 Boss、御兽名称和视觉方案仍可在后续美术/剧情阶段调整。
5. 首发终局采用“被污染的封印守兽 + 裂隙妖物”的复合威胁方向。
