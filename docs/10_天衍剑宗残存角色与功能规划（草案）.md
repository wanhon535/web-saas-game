## 1. 已确认结构

天衍剑宗隐世后不只剩主角一人：仍有少数长老、弟子、守宗力量留存，另有失散或沉睡成员。该结构用于让宗门衰败、重建与后续创建宗门玩法具备叙事基础。

| 角色类型 | 首发职责 | 当前状态 | 战斗定位 |
|---|---|---|---|
| 镇宗长老·裴观岳 | 主线、封妖历史、境界突破、Boss 情报 | 留守宗门 | 剧情/NPC，不作为首发可操作角色 |
| 炼器执事·苏照微 | 飞剑、装备、法器强化与打造引导 | 第四章主线寻回 | 剧情/NPC，不作为首发可操作角色 |
| 年轻弟子·叶轻舟 | 新手任务、日常、活动、轻松剧情与玩家陪伴 | 留守宗门 | 剧情/NPC，不作为首发可操作角色 |
| 守宗灵兽·玄曜 | 御兽图鉴、羁绊、驯兽等级和结契引导 | 第一章后逐步苏醒 | 剧情/NPC，不占玩家出战御兽位 |
| 失散成员·谢无归（关键线） | 主线章节救援、支线、功能与后续内容入口 | 第三章起出现线索，第五章受妖气污染后现身 | 首发以 NPC/Boss 分支为主，后续可转化为角色/宗门成员 |


## 1.2 第一版核心角色设定（由开发总控拟定）

| 角色 | 核心形象与性格 | 剧情职责 |
|---|---|---|
| 万剑真君 | 主角本名随失忆主线逐步揭示；外在冷静克制、行事谨慎务实，对认可之人有明确守护底线 | 天衍剑宗末代宗主、封妖传承承载者、玩家视角核心 |
| 裴观岳 | 年长、沉稳、寡言，知道部分真相但受封印誓约限制 | 推动主线、解释境界与 Boss 情报、在关键处揭露宗门衰败真相 |
| 苏照微 | 直率严谨、对炼器近乎苛刻，擅长用行动表达关切 | 引导装备、法器、飞剑和打造；第四章回归宗门 |
| 叶轻舟 | 年轻、机敏、乐观但不莽撞，是宗门日常气息的代表 | 引导任务、活动与轻量剧情，并串联失散成员线索 |
| 玄曜 | 守宗灵兽，古老克制，对主角既熟悉又保持戒备 | 引导御兽、羁绊和驯兽等级，保存部分封妖记忆 |
| 谢无归 | 主角旧日同门，沉静坚韧；因追查裂隙而受污染，立场被误解 | 中后期冲突核心，承载净化、击杀或牺牲的分支结局 |

> 以上名称、人物关系和视觉方向为本项目原创设定；不复用任何外部作品的角色、故事或视觉资产。

## 1.3 主线目标推进顺序（已确认）

采用“守住宗门 → 追查封印碎片与失散成员 → 稳定裂隙”的三层递进：

1. **第一至二章**：守住天衍剑宗，建立安全据点，理解飞剑、掉落、御兽和装备的基础循环。
2. **第二至四章**：沿封印碎片线索推进，同时寻找失散成员；在第四章寻回苏照微并开启完整打造线。
3. **第五章**：裂隙扩大，谢无归受污染的真相出现，主角必须在继续收服妖兽与保护宗门之间作出更高压判断。
4. **第六章**：集合宗门残存力量，面对终局复合威胁，稳定裂隙并决定谢无归的结局。

## 1.4 谢无归分支结局（已确认方向）

- 玩家通过支线、净化材料、御兽羁绊与关键选择累积“归心”条件。
- 条件充分时：可净化谢无归，使其回归天衍剑宗并协助终局封妖。
- 玩家选择决断或条件不足时：谢无归作为高压 Boss 被击败，获得击杀路线奖励。
- 在特定高条件和关键选择下：谢无归可为封印裂隙牺牲，保留情感收束并解锁特殊纪念/宗门奖励。
## 1.1 角色与主角表现原则（已确认）

- 前几章以宗门引导角色带领玩家逐步了解装备、御兽收集、飞剑/武器打造等核心内容；功能必须通过主线和剧情自然开放。
- 守宗灵兽定位为长期引导 NPC，不占玩家携带或出战御兽位。
- 失散成员中可加入被妖气污染、可能背叛或被误解的关键角色，形成主线冲突和后续救赎/对抗分支。
- 万剑真君的性格参考《仙逆》中王林的**高层特质**：冷静克制、谨慎务实、意志坚定、重视自己认可的人；不得复用《仙逆》的角色姓名、剧情事件、关系、台词、世界观设定或视觉标识。万剑真君、天衍剑宗和“万剑封妖”必须保持原创表达。

## 2. 首发角色功能边界

1. 玩家首发仅操作万剑真君；不因存在宗门成员而提前改为多角色阵容。
2. 每名宗门 NPC 必须同时承担至少一项明确功能或剧情推进，避免只做静态摆设。
3. 装备、御兽、境界、任务、活动等入口优先通过剧情自然解锁，而非开局一次性全部展示。
4. 创建宗门、成员协作、公会战等社交功能为后续版本内容；首发只铺垫天衍剑宗复兴目标。

## 3. 六章出场与功能建议

| 章节 | 剧情角色作用 | 解锁或强化内容 |
|---|---|---|
| 第一章：幽冥荒原 | 镇宗长老、年轻弟子完成基础剧情引导；守宗灵兽出现苏醒线索 | 战斗、飞剑基础、掉落、首个 Boss 抓捕 |
| 第二章：灵木妖林 | 守宗灵兽恢复部分神智，说明灵兽污染与结契规则；失散成员线索出现 | 御兽培养、羁绊、驯兽等级 |
| 第三章：赤炎裂谷 | 年轻弟子或失散弟子提供裂隙妖物活动情报；引入装备收集与武器打造线索 | 移动躲避、主动御兽技能、装备收集、任务体系 |
| 第四章：沧澜灵渊 | 寻回炼器长老/法器执事，发现天衍剑宗镇妖遗迹 | 装备强化、法器、武器打造、困难 Boss 雏形 |
| 第五章：风雷古道 | 镇宗长老揭露宗门隐世原因；失散成员协助应对裂隙扩张 | 多次虚弱、逃跑压力、高阶驯服条件 |
| 第六章：万兽封天台 | 宗门残存成员共同完成终局封妖仪式，主角恢复关键记忆 | 首发终局、裂隙稳定、后续宗门复兴伏笔 |

## 4. 后续版本衔接

- 通过找回失散成员、修复宗门建筑、净化守宗灵脉等内容，逐步形成“天衍剑宗复兴”长期目标。
- 后续创建宗门玩法可从天衍剑宗复兴延伸：玩家建立或加入宗门，进行协作任务、宗门 Boss、资源捐献与社交内容。
- 后续若开放新可操作角色，优先使用已建立的失散成员、长老传人或相关势力角色，保证角色投放与主线叙事一致。

## 5. 下一轮待确认

2. 谢无归的“净化回归、击杀、牺牲”三种结局是否保留，及玩家是否需要明确看到选择提示。
3. 第一章至第四章的功能解锁顺序：装备收集、御兽培养、武器打造、任务、扫荡、资源副本分别在哪一章开放。
4. 核心角色的外观方向：服饰、年龄感、性别设定、武器与配色。
