# 正式版产品蓝图（沟通草案）｜修仙御兽：万剑封妖

> 文档状态：**沟通草案，不替代 P0 基线**  
> 版本：0.1  
> 最后更新：2026 年 9 月 9 日  
> 用途：沉淀已确认的正式版方向，作为后续世界观、内容规模、数值、服务端与上线规划的讨论底稿。

## 1. 文档边界

- `01_P0_产品与开发基线.md` 仍是当前客户端 P0 的唯一有效需求。
- 本文描述 P0 验收后逐步建设的正式版方向；其中标记为“待确认”的内容不得直接进入当前 P0。
- 正式版首发目标：完成产品整体核心内容的约 70%–80%，形成可长期运营的完整推图、御兽、装备和挑战循环。

## 2. 已确认的游戏定位

**题材与体验**：国风修仙、万剑镇妖、御兽收集、推图闯关、装备与灵宠养成。

**长期主循环**：

```text
推主线章节 → 自动御剑守线战斗 → 获得装备/材料 → 挑战章节 Boss
→ 抓捕御兽或完成击杀 → 获得御兽、第二阶段奖励或碎片
→ 养成角色、装备、飞剑与御兽 → 挑战更高章节、精英和困难 Boss
```

**正式版战斗原则**：

1. 万剑真君是首发唯一角色；后续版本再逐步投放新角色。
2. 自动御剑和守线仍是主要操作，保证低门槛推图体验。
3. 角色可在屏幕下半区域前后左右移动；普通关卡不强制高频走位。
4. 高难副本以 Boss 范围技能、冲锋、弹幕、地面危险区等机制提高移动与操作价值。
5. 御兽可携带 1–2 只、同时仅 1 只出战，支持切换和成长羁绊。

## 3. Boss、抓捕与阶段奖励（已确认）

### 3.1 阶段定义

- Boss 生命降至配置的抓捕阈值时，进入虚弱/可抓捕状态；此时视为**第一阶段完成、第二阶段开始**。
- 未进入虚弱血线前战斗失败：不获得阶段奖励。
- 进入虚弱血线后未完成击杀、或 Boss 逃跑：按第一阶段完成结算，不获得击杀碎片。
- 最终击杀 Boss：获得完整第二阶段奖励与 Boss 碎片。

### 3.2 抓捕循环

1. 每次 Boss 进入虚弱状态均可提供抓捕窗口。
2. 常规 Boss 默认可配置 2–3 次虚弱；特殊后期 Boss 的次数、阶段技能、回血与状态独立配置。
3. 抓捕消耗抓捕道具。
4. 抓捕成功：立即结束战斗，获得该 Boss 御兽与完整第二阶段奖励，但不获得击杀碎片。
5. 抓捕失败：按该 Boss 当前虚弱次数与配置，可能触发再次狂暴、恢复正常、回血、技能强化或逃跑。
6. 抓捕失败后继续输出，Boss 可以再次进入虚弱并提供新抓捕机会。

### 3.3 逃跑规则

- Boss 有基础逃跑概率。
- 血量越低、虚弱次数越多时，相关逃跑概率可逐步提高。
- Boss 逃跑后，玩家需在限定时间内完成击杀；成功则获得第二阶段奖励与碎片，失败则按第一阶段结算。

### 3.4 两条收益路线

| 路线 | 结果 | 核心收益 |
|---|---|---|
| 抓捕路线 | 抓捕成功，战斗结束 | 御兽 + 完整第二阶段奖励，不含击杀碎片 |
| 击杀路线 | 最终击杀 Boss | 完整第二阶段奖励 + Boss 碎片 |
| 保底路线 | 进入虚弱后未击杀 / 逃跑 | 第一阶段通关奖励 |

## 4. 正式版成长系统方向

### 4.1 角色与飞剑

- 首发角色：万剑真君。
- 长期成长：飞剑、法宝、角色等级及后续角色专属武器。
- 后续角色：在主线或版本内容成熟后增加，不提前干扰 P0 的单角色体验。

### 4.2 御兽

- 御兽有等级、品质、属性、主动技能、培养和特定组合羁绊。
- 切换御兽存在冷却；切换时自动释放当前御兽的切换技能，其余主动技能可由玩家释放。
- 常规羁绊需要培养达标后生效；特殊御兽可有例外规则。

### 4.3 装备

- 有部位、品质、强化、固定词条与套装。
- 大多数装备为通用装备；武器和特定装备按角色穿戴。
- 重复装备可分解；装备可存在出售与交易方向。
- 特殊装备可带少量随机词条，并通过打造等后续系统产出。

## 5. 资源与副本方向（待数值方案确认）

### 已确认原则

- 不采用传统体力作为普通副本进入限制。
- 普通副本可反复挑战并产出养成材料。
- 高阶副本使用普通内容、活动或其他玩法产出的挑战门票进入。
- 需要三星、扫荡、战力推荐、离线收益与首通奖励。

### 建议的“无限可玩、有效收益受控”模型

1. 普通主线不限进入，始终提供基础掉落。
2. 高价值材料采用首通、阶段奖励、每日/每周高收益次数与平滑递减的组合控制，不直接阻止游玩。
3. 高阶 Boss、资源本和特殊挑战使用可获得的门票，门票不能只靠付费取得。
4. 扫荡只开放给三星通关关卡，并消耗对应奖励次数或门票。
5. 核心突破材料优先绑定；可交易物品仅开放部分稀有物品，并配置交易手续费、上架限制、价格和账号门槛。

> 待确认：具体收益次数、门票来源、交易品类、广告与付费商品边界。

## 6. 首发内容骨架（建议，待故事线确认）

首发采用“剧情与推图量平衡”方向：

```text
主线章节
├─ 普通关：剧情推进、基础养成材料、装备掉落
├─ 精英关：高难机制、稀有装备与特殊材料
├─ 章节 Boss：抓捕御兽的主要来源
├─ 困难 Boss：多次虚弱、逃跑与两阶段挑战的主要承载
├─ 资源副本：仙石、装备强化、御兽培养等资源
└─ 日常/周常/活动：维持长期游玩与内容循环
```

### 建议的主线结构（仅为讨论提案）

| 阶段 | 地区/剧情功能 | 核心体验 |
|---|---|---|
| 第一章：幽冥荒原 | 妖潮初现，万剑真君镇守护宗大阵 | 建立守线、掉落与首次抓捕认知 |
| 第二章：灵木妖林 | 妖兽异化来源初露，御兽契约体系展开 | 属性克制、首批御兽羁绊 |
| 第三章：赤炎裂谷 | 封印碎片引发妖火失控 | 移动躲避与范围机制开始出现 |
| 第四章：沧澜灵渊 | 灵脉失衡，水域妖兽与遗迹线索 | 困难 Boss 与装备打造线索 |
| 第五章：风雷古道 | 妖界裂隙扩大，宗门势力加入 | 多次虚弱、逃跑与高压战斗 |
| 第六章：万兽封天台 | 追溯万剑封妖真相，首发主线收束 | 首发终局 Boss 与后续版本悬念 |

> 本表不代表已定章节名称、Boss 或剧情；需要在世界观确认后再细化为关卡、怪物、Boss、御兽和奖励清单。

## 8. 实施分层

1. **当前 P0**：只完成第一章单角色普通副本的稳定可玩闭环，维持一次虚弱、一次抓捕的简化规则。
2. **正式版蓝图阶段**：确认世界观、章节数、首发内容量、货币和商业化边界，输出系统规格、数值表与数据模型。
3. **正式版基础设施阶段**：重建 MySQL、账号、存档、配置、战斗结算、交易与日志能力；再评估抖音小游戏适配。
4. **内容生产阶段**：按章节和系统优先级制作关卡、Boss、御兽、装备、任务、活动和 UI。
5. **上线准备阶段**：性能、移动端交互、数据分析、经济校验、交易安全、平台接入、测试与内容审核。

## 9. 下一轮必须确认的问题

1. 世界观基调：妖兽是被妖气侵蚀、可净化的灵兽，还是本质敌对的妖族，或两者并存？
2. 万剑真君身份：宗门弟子、护宗长老、掌门、封妖传人，还是其他设定？
3. 主线终局：首发阶段是重新封印妖界裂隙、找到失落封印，还是击败某个终局妖王？
4. 首发章节规模：故事确认后，确定大章节、普通关、精英关、Boss 与可抓捕御兽的数量目标。
5. 交易与商业化：明确可交易品类、账号门槛、广告、月卡、礼包和货币边界。
