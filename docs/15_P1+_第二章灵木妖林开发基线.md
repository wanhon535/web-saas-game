# P1+ 第二章《灵木妖林》开发基线

- **状态**：开发中
- **建立日期**：2026 年 9 月 13 日
- **产品确认**：进入第二章主线、新地图与新妖兽 / Boss 的客户端开发。

## 1. 本轮目标

在不改变第一章已封版玩法的前提下，为《修仙御兽：万剑封妖》补齐可连续推进的第二章客户端闭环：

`第一章 1-10 结算 → 第二章 2-01 解锁 → 灵木妖林推图 → 2-06 精英 Boss → 2-09 章节 Boss → 2-10 章节结算`

## 2. 已确认主题内容

- 地图：**灵木妖林**
- 精英 Boss：**玄藤鹿灵**
- 章节 Boss：**碧瞳树蛟**
- 世界观：天衍剑宗追循寻木青雀留下的封印线索，进入被裂隙妖气侵蚀的灵木妖林；健康灵兽与裂隙妖物共同构成敌人。

## 3. 本轮实现范围

1. 新增第二章 2-01 至 2-10 的关卡、剧情、数值、首通 / 重复奖励配置。
2. 章节进度界面按第一章、第二章分组收纳；章节主视觉、战斗标题与结算文案随当前关卡动态变化。
3. 灵木妖林战斗场景：深青夜林、巨木、妖藤、树根、薄雾、封印碎片。
4. 第二章普通妖物、玄藤鹿灵、碧瞳树蛟使用独立的 Canvas 轮廓与战斗表现。
5. 玄藤鹿灵保留一次轻量“妖藤唤灵”表现；不引入高频强制躲避。
6. 第一章存档、装备、寻木青雀、结契教学与全部既有测试必须兼容。
7. 建立第二章专项自动检查、更新交接日志、建立 Git 回档并推送。

## 4. 明确不在本轮实现

- 第二只御兽获得、切换、羁绊与出战位扩展。
- 多次虚弱、抓捕失败分支、逃跑、回血、复杂两阶段抓捕的完整玩法。
- 随机词条、打造、交易、账号、MySQL、云存档、抖音 SDK、支付及第三章。

> 碧瞳树蛟本轮以“斩灭妖核、取得封印线索”的章节 Boss 收束，不会在尚未完成第二御兽体系时强行接入结契出战。

## 5. 验收标准

- 新档仅开放 1-01；完成 1-10 后才开放 2-01。
- 2-01 至 2-10 均可顺序解锁，2-06 为玄藤鹿灵精英、2-09 为碧瞳树蛟章节 Boss、2-10 为结算节点。
- 第二章有清晰国风修仙妖林场景，Boss 外形不复用寻木青雀。
- 第二章奖励配置引用的材料、装备均有效；可继续穿戴及结算。
- 旧档可平滑迁移，第一章完成状态、寻木青雀、装备和已有材料不丢失。
- P0、P1 第一章及第二章专项自动检查全部通过。
