> 生效日期：**2026 年 9 月 11 日**
> 前置版本：P1.1（回档点 `cc39470`）
> 本文优先级：本文取代 `12_P1_第一章扩展基线.md` 中“仅前三普通关、暂不进入 1-04 与御兽”的范围限制；P0 核心战斗与首次结契兼容规则仍必须保留。

## 1. 已确认目标

完成可独立试玩的第一章《幽冥荒原》：

```text
1-01 至 1-10 推图 → 普通妖潮 / 精英守关 / 章节 Boss →
装备与材料成长 → 首次净化结契 → 青雀实际协战 → 章节结算
```

客户端继续使用浏览器本地存档。第一章完成后，玩家可以保留角色、装备、寻木青雀与章节资源，等待第二章接续；不在本阶段接入账号、MySQL、抖音小游戏 SDK 或服务端。

## 2. 第一章可开发范围

### 2.1 关卡与推进

- `1-01 荒原警兆`、`1-02 残阵回响`、`1-03 剑痕拾遗`：沿用已完成内容。
- `1-04 守山灵识`、`1-05 阵眼试炼`、`1-07 青羽秘纹`、`1-08 妖潮压境`：普通守线关，以配置化妖潮、掉落、短对白和首通奖励区分。
- `1-06 石甲拦路`：精英守关；含可见的精英目标、较高护阵压力、稳定首通奖励。
- `1-09 雀鸣于荒原`：章节 Boss 寻木青雀；首次到达时为强引导、100% 成功的净化结契教学。
- `1-10 山门余火`：章节收束节点；结算首章进度、青雀结契成果与下一章线索，不制作第二章。
- 关卡按顺序解锁，首通与重复奖励分别记录；刷新后保持。

### 2.2 战斗规则

- 保留 P0 的下半屏移动、自动御剑、守线、妖物越线扣护阵 HP、掉落自动吸附、暂停、失败与结算。
- 普通关与精英关不开放抓捕；抓捕入口仅用于 `1-09` 的寻木青雀。
- `1-06` 精英不要求躲技能；以石甲、接近阵线和少量召唤物表达压力，不改变自动战斗为主的核心。
- `1-09` 首次结契：Boss 到达虚弱阈值后暂停并引导使用结契符；选择任一教学镇妖器均 100% 成功，成功立即结束战斗并获得寻木青雀。
- 已完成首次教学的旧档可重复挑战 Boss，并保持 P0 已有的“常规抓捕概率、失败狂暴/回血/加速、继续诛灭”的兼容路径。

### 2.3 成长与产出

- 固定属性装备：荒原护腕、守阵法衣、温灵玉佩、石甲镇符；不做随机词条、套装、打造或交易。
- 材料：剑胚残铁、阵纹灵砂、清灵结契符、青雀灵羽；仅服务首章已实现的奖励、说明和最小养成。
- 第一只御兽：寻木青雀可在结契后设为出战御兽，拥有一个主动协战技能；可使用青雀灵羽进行有限等级培养。首章只有一只可用御兽，不制作第二只御兽、切换或羁绊。
- 现有飞剑祭炼、固定装备穿戴与属性实装继续有效。

### 2.4 叙事与引导

- 主题固定为：天衍剑宗末代宗主万剑真君守宗、镇妖、净化与结契。
- 引导角色限定为裴观岳、叶轻舟、玄曜；仅短对白与功能引导，不制作配音、立绘、长过场或分支剧情。
- 首章结尾仅给出“灵木妖林、封印碎片、失散成员线索”，不开发后续章节内容。

## 3. 明确不在 P1 内

- 第二章及以后关卡；
- 第二只御兽、御兽切换、羁绊、多宠编队；
- Boss 多次虚弱、逃跑、复杂二阶段、碎片循环；
- 多角色、随机词条、装备打造/分解/交易、商城；
- MySQL、账号、云存档、服务端结算、抖音 SDK、支付、社交与运营系统。

## 4. 验收标准

1. 新存档可完整推进 `1-01` 至 `1-10`，章节地图、锁定状态、首通和重复奖励均正确。
2. `1-06` 精英战与 `1-09` 章节 Boss 可实际通关；首次 Boss 抓捕稳定 100% 成功。
3. 结契后寻木青雀会在战斗中提供可见、可使用的协战技能，并可进行最小等级培养。
4. 固定装备、材料、飞剑、护阵、仙石、御兽和章节进度刷新后不丢失；P0 旧存档可平滑迁移。
5. P0 回归、既有 P1.1 回归与新增第一章完整版回归全部通过。
6. 每个可试玩闭环同步更新进度交接日志、README 和 Git 回档点，并推送至 GitHub。

## 5. 分段交付顺序

1. **P1.A**：正式关卡配置、`1-04` 至 `1-08`、精英关与完整推进。
2. **P1.B**：`1-09` 章节 Boss 接入、首次结契兼容、`1-10` 章节结算。
3. **P1.C**：寻木青雀协战、最小培养、UI 引导、全量回归与体验整理。

> 交付顺序用于开发与回档，不表示可跳过前置验收。任何超出本文件的内容，须另行确认后再进入开发。
