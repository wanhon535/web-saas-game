# P0 产品与开发基线｜修仙御兽：万剑封妖

> 文档状态：**生效｜唯一事实源**
> 版本：P0.1
> 最后更新：2026 年 9 月 9 日

## 1. P0 目标

完成一局可完整游玩的「幽冥荒原」普通副本，让玩家能理解并重复体验：

**进入副本 → 单人守线自动战斗 → 获取掉落 → 面对 Boss → 抓捕或击杀 → 结算 → 祭炼飞剑 / 查看收获 → 再次挑战。**

P0 的目标是验证战斗节奏、守线压力、掉落反馈、抓捕抉择和最小局外成长；不是提前制作长线运营游戏。

## 2. 主题与体验原则

- 题材：国风修仙、御兽、万剑镇妖。
- 场景：第一章「幽冥荒原」，宗门外的妖气荒原。
- 主角：万剑真君，可在画面下半区域移动并镇守护宗阵眼。
- 情绪：前段从容清妖，中段感受到妖潮逼近，Boss 阶段出现“收服还是诛灭”的短暂选择。
- 视觉：Q 版国风、厚描边、青灰荒原、暖金主按钮、羊皮/青玉卡片；不得套用西幻国王、城堡、炮台或骑士内容。

## 3. P0 范围

### 必做内容

1. **唯一关卡**：第一章「幽冥荒原」普通副本。
2. **唯一战斗角色**：万剑真君，初始仅一柄飞剑自动攻击。
3. **守线规则**：妖物从上方压境，越过底线会扣除护宗大阵生命。
4. **波次流程**：3 波小妖后出现 Boss「寻木青雀」。
5. **自动拾取**：仙石和法器进入吸附范围后自动获得。
6. **Boss 抓捕**：Boss 虚弱时提供一次抓捕选择。
7. **抓捕失败补救**：Boss 狂暴并回血，玩家可继续击杀以获得额外奖励。
8. **四种结局表达**：普通斩妖、收服成功、狂暴后斩杀、护阵失守。
9. **局外最小成长**：飞剑祭炼、法器展示、灵宠展示、本地存档。
10. **可重复试玩**：结算后返回入口，再次进入副本不丢失局外收获。

### 明确不做

- 多角色阵容、六战位、炮台或职业切换。
- 第二章及以上内容；史诗、深渊、团本等副本阶梯。
- 多宠物出战、宠物编队、宠物技能、宠物升星。
- 抽卡、商城、公会、排行榜、广告、首充和付费设计。
- 装备 3 合 1、炼狱晶核、保底锻造和复杂材料链。
- 账号体系、MySQL 联调、实时防作弊、平台 SDK 和抖音部署。

## 4. 玩家流程与状态

```text
荒原入口
  → 点击「踏入荒原」
  → 第 1 波 / 第 2 波 / 第 3 波小妖
  → Boss「寻木青雀」出现
  → Boss 生命降至虚弱阈值
      ├─ 使用镇妖符或镇妖葫芦
      │    ├─ 成功：收服寻木青雀 → 收服结算
      │    └─ 失败：Boss 狂暴、回血、加速 → 继续战斗
      │                                  ├─ 击杀：狂暴斩杀结算
      │                                  └─ Boss 越线：护阵失守结算
      └─ 不抓捕 / 继续攻击
           ├─ 击杀：普通斩妖结算
           └─ Boss 或小怪越线导致护阵 HP 为 0：护阵失守结算
  → 奖励写入本地存档
  → 返回荒原入口 / 法宝仙匣 / 万灵御兽录
```

## 5. 核心规则

### 5.1 战斗

- 主角可在画面下半区域前后左右移动；移动只用于拾取站位与后续高压关卡躲避，不改变自动御剑的核心战斗优先级。
- 飞剑自动寻找离阵线最近的存活妖物。
- 初始飞剑数量恒为 1；P0 内不提供局内加剑、随机技能或职业切换。
- 小怪和 Boss 都可越线；越线即移除并造成护阵伤害。
- 护宗大阵生命降为 0 时本局立刻失败，已自动吸收的基础战利品保留。

### 5.2 掉落

- 小怪死亡掉落仙石。
- Boss 死亡掉落仙石与至少一件法器。
- 狂暴 Boss 死亡掉落更多物品；体现“抓捕失败后仍有可挽回收益”。
- 掉落进入玩家 380 范围内后自动磁吸；快速飞向角色并写入本局奖励。

### 5.3 抓捕

- Boss 生命降至虚弱阈值时，战斗暂停并展示抓捕面板。
- 首次新手抓捕是结契教学：镇妖符或镇妖葫芦均必定成功，且必须完成结契，不能选择继续诛灭。
- 镇妖符：首次教学后不消耗库存，成功率较低。
- 镇妖葫芦：首次教学后消耗 1 个库存，成功率更高。
- 首次收服后，重复挑战恢复常规抓捕规则；继续诛灭不消耗道具，关闭抓捕面板并恢复战斗；Boss 保持常态，击杀后进入普通斩妖结算。
- 成功：获得「寻木青雀」及其法器奖励，直接结算。
- 失败：关闭抓捕面板，Boss 狂暴、回复部分生命、移动加速；玩家继续自动战斗。
- 每个 Boss 仅出现一次抓捕选择；选择抓捕或继续诛灭后均不再重复弹出，避免破坏抉择价值。

### 5.4 局外成长与存档

- 仙石用于祭炼青霄飞剑。
- 每次祭炼提升飞剑伤害；消耗随等级提高。
- 法器仅用于“收获感和展示”，本期不扩展复杂装备槽属性。
- 灵宠仅记录「寻木青雀」是否收服，本期不提供额外战斗加成。
- 存档数据只使用浏览器本地存档；P0 验收后才迁移 MySQL。

## 6. P0 完成定义

满足全部条件才可视为 P0 可玩闭环完成：

1. 新用户可打开试玩页并成功进入战斗。
2. 三波小怪、Boss、越线扣血、自动攻击、自动拾取全程正常。
3. 新手可完成首次必定成功的结契教学；完成后能完整跑通普通斩妖、抓捕成功、抓捕失败后狂暴斩杀、护阵失守等结果。
4. 结算奖励、飞剑祭炼、法器展示、灵宠展示在刷新页面后仍能保留。
5. 不出现六角色、多副本、商城等 P1 内容入口或文案。
6. 通过 `04_P0_QA验收与回归清单.md` 的关键用例。

## 7. 变更规则

- 玩法、范围、数值、UI 文案发生变化时，先更新本文件或 `02_P0_数值与产出配置说明.md`，再改代码。
- 未写入本基线的系统默认不做。
- 任何涉及 P1 的提议只能记录在未来规划中，不得混入当前 P0 任务。
