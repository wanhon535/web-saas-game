| 目录 | 内容 |

## 阅读顺序

1. 根目录 `AGENTS.md`：先确认、后开发与测试/Git 规则；
2. 根目录 `README.md`：当前可玩内容、启动方式和项目边界；
3. 根目录 `项目开发计划书.md`：当前计划、已实现状态、路线与待确认事项；
4. 本目录中与本次功能直接相关的当前基线或验收报告；
5. `07_开发进度与交接日志.md` 的最新记录；
6. 仅在需要追溯时阅读 `archive/` 中的历史资料。
