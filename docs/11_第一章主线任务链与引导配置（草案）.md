## 1. 本章定位

- **章节名称**：第一章·幽冥荒原。
- **主角短期目标**：在妖潮压境时守住天衍剑宗残存山门，确认妖潮异常来源。
- **章节叙事作用**：让万剑真君从失忆和沉寂中苏醒，建立“守宗—镇妖—结契”的第一层动机；在章节结尾得到第一块封印碎片线索与失散成员线索。
- **战斗定位**：固定下方守线、自动御剑为主；不在第一章强制玩家移动躲技能。高难躲避和下半屏移动从第三章开始引入。
- **章节内容建议**：8 个普通关、1 个精英 Boss 关、1 个章节 Boss 关；正式量产时可根据节奏压缩为 8–10 个关卡。

## 4. 章节 Boss：寻木青雀

### 4.1 剧情定位

寻木青雀原为幽冥荒原外围的守林灵禽，被裂隙妖气侵蚀后失控。它不是纯粹恶意的敌人，因此既能够成为第一只可结契御兽，也能承载“净化与收服”的第一层主题。

### 4.2 第一章专用战斗与抓捕表达

1. 战斗前半段以直线妖风、召唤低阶妖物、短暂加速为主，避免要求玩家在新手期进行复杂走位。
2. 血量到达抓捕阈值后进入一次明确的虚弱窗口，作为首次抓捕教学。
3. 抓捕成功：立即结束战斗，获得寻木青雀御兽与章节 Boss 抓捕奖励；不额外发放击杀碎片。
4. 玩家选择不抓捕或抓捕失败后完成击杀：获得完整章节 Boss 击杀奖励与寻木青雀碎片。
5. 未完成击杀或未进入虚弱状态时，按正式版阶段奖励规则处理；具体数值由后续 Boss 配置表统一制定。

> 正式版中高阶 Boss 的多次虚弱、逃跑、回血和高阶抓捕门槛不在第一章首次教学中堆叠；第一章只建立最小可理解闭环。

## 5. 功能解锁节奏

| 节点 | 对玩家展示 | 本章边界 |
|---|---|---|
| 1-01 | 战斗与护宗大阵 | 只教守线和自动御剑，不加入复杂移动需求 |
| 1-03 | 掉落与自动吸收 | 展示仙石、基础装备、祭炼材料三类基础产出 |
| 1-05 | 装备查看与穿戴 | 仅开放基础装备，不开放复杂打造或随机词条 |
| 1-04 / 1-09 | 御兽图鉴与首次结契 | 可展示御兽位置、图鉴和基础属性；首只御兽来自青雀抓捕 |
| 1-10 | 章节结算与主线追踪 | 提示第二章目标和封印碎片线索 |
| 后续章节 | 飞剑打造、御兽培养、羁绊、任务、扫荡、资源副本 | 按主线自然开放，不在第一章一次性堆出全部入口 |

## 6. 本章奖励与资源边界

- **普通关**：仙石、基础装备、飞剑祭炼材料、少量结契符来源。
- **精英 Boss**：稳定产出装备强化材料与章节专属制作素材。
- **章节 Boss**：抓捕路线提供御兽和抓捕奖励；击杀路线提供完整 Boss 奖励与碎片。
- **首通奖励**：用于保证首次推进体验，不替代后续资源副本和长期经济配置。
- 本文不定义具体掉率、数值、货币数量或付费内容；这些必须在正式版数值与经济设计阶段单独制定。

## 7. P0 对照与制作边界

当前 P0 仅验证“守线战斗、自动飞剑、掉落自动吸收、一次弱化抓捕、失败后击杀补救、飞剑/法器/灵宠展示、本地存档”的最小闭环。

因此：

- P0 可以继续使用寻木青雀作为验证 Boss，但不要求实现本章所有 10 个任务、NPC 剧情、精英 Boss 或正式版系统解锁。
- 本文的任务链不得反向改写 `01_P0_产品与开发基线.md`；P0 的任何玩法改动仍须单独确认、测试、记录并建立 Git 节点。
- 正式版进入内容生产前，需要将本章草案拆分为关卡配置、对白、Boss 配置、奖励表、资产清单和验收用例。
