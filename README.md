# 修仙御兽：万剑封妖

> **开发阶段：P1 第一章完整版客户端（已完成）**
> **当前内容：第一章 `1-01` ～ `1-10` 已可完整推进，含精英、章节 Boss、首次结契、御兽协战/培养、固定装备材料与章节结算。**
> **最后更新：2026 年 9 月 12 日**

《修仙御兽：万剑封妖》是一款以国风修仙、御兽收服与万剑镇妖为主题的轻量战斗游戏原型。玩家扮演天衍剑宗末代宗主「万剑真君」，在幽冥荒原守住护宗大阵、击退妖潮，并收服守关大妖「寻木青雀」。

当前仓库已完成 **P1 第一章完整版客户端**。本阶段为浏览器本地试玩原型：使用浏览器本地存档，不接入账号、MySQL、云存档、平台 SDK、支付或抖音小游戏能力。

---

## 当前可玩内容

- **第一章完整推进**：顺序推进 `1-01` 至 `1-10`；包括普通试炼、`1-06` 精英「荒原石甲兽」、`1-09` 章节 Boss「寻木青雀」及 `1-10` 章节结算。已通关节点可重复挑战。
- **单角色守线战斗**：万剑真君可在战场下半区域移动，支持鼠标/触屏拖动与方向键 / WASD；自动御剑初始为 1 柄青霄飞剑，攻击间隔为 0.85 秒。
- **阵线压力与拾取**：妖物越过护宗阵线会扣除护宗大阵 HP，HP 归零后战斗失败。仙石、材料和装备掉落进入主角吸附范围后会自动拾取。
- **精英与 Boss**：石甲兽会召唤碎石妖鼠；寻木青雀在首次结契时提供 100% 成功的教学抓捕。重复挑战保留常规抓捕、失败狂暴/回血/加速与继续诛灭分支。
- **固定装备闭环**：通过首通获得荒原护腕、守阵法衣、温灵玉佩、石甲镇符等固定法器；可在「法宝」页穿戴/卸下，实际影响伤害、护阵上限或仙石结算。
- **御兽协战与培养**：首通章节 Boss 后获得并默认出战寻木青雀，可使用「青翎回风」造成范围伤害与迟缓；消耗仙石和青雀灵羽可培养至 Lv.5。
- **本地存档兼容**：进度、装备、材料、御兽及章节结算保存在浏览器本地；旧版 P0/P1.1 存档会自动迁移到当前结构。

## 本地启动

### 环境要求

- Node.js 18 或更高版本
- Chromium 内核浏览器（Chrome / Edge 等）

### 启动步骤

```powershell
node .\server\start_server.js
```

随后在浏览器打开：

```text
http://127.0.0.1:3000/
```

> 项目无需执行 `npm install`；本地服务仅用于提供静态试玩文件。

## 操作说明

| 操作 | 方式 |
|---|---|
| 进入副本 | 首页选择已解锁关卡后点击「进入试炼」 |
| 移动主角 | 战斗画布内拖动；或使用方向键 / WASD |
| 暂停战斗 | 战斗页右上角暂停按钮 |
| Boss 抓捕 | Boss 虚弱后点击镇妖符或镇妖葫芦 |
| 释放御兽协战 | 获得寻木青雀后，在战斗底部点击「青翎回风」 |
| 祭炼飞剑 | 洞府底部进入「法宝」后点击祭炼 |
| 穿戴法器 | 「法宝」页的「已获法器」中点击「穿戴」；再次点击可卸下 |
| 培养御兽 | 「灵宠」页消耗 180 仙石和 1 青雀灵羽点击「培养御兽」 |
