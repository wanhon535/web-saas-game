# 修仙御兽：万剑封妖

> 当前阶段：**P0｜第一章「幽冥荒原」普通副本闭环**
> 最后整理：2026 年 9 月 9 日

## 当前试玩

1. 在项目根目录运行：`node .\server\start_server.js`
2. 浏览器打开：`http://127.0.0.1:3000/`

当前版本是 **H5 单页 + Canvas 2D** 原型。它只服务于 P0 的可玩验证，不包含 MySQL、账号、平台 SDK 或正式服务端。

## P0 一句话定义

万剑真君镇守护宗大阵，以一柄自动飞剑抵挡幽冥荒原妖潮；击败或收服寻木青雀，带着仙石和法器回到洞府继续成长。

P0 不做多角色、多职业、多灵宠编队、第二章、史诗/深渊、商城、公会、抽卡、复杂合成、MySQL 联调和抖音小游戏部署。
