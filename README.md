# 修仙御兽：万剑封妖

> **开发阶段：P1+ 第二章《灵木妖林》与战斗生存规则（已完成）**
> **当前内容：第一、二章 `1-01` ～ `2-10` 可连续推进；含精英、章节 Boss、主角/护阵双生命、近战躲避、Boss 双目标远程攻击、首次结契、御兽协战/培养与固定装备材料。**
> **最后更新：2026 年 9 月 13 日**

《修仙御兽：万剑封妖》是一款以国风修仙、御兽收服与万剑镇妖为主题的轻量战斗游戏原型。玩家扮演天衍剑宗末代宗主「万剑真君」，在幽冥荒原守住护宗大阵、击退妖潮，并收服守关大妖「寻木青雀」。

当前仓库已完成 **P1+ 第二章《灵木妖林》客户端**。本阶段为浏览器本地试玩原型：使用浏览器本地存档，不接入账号、MySQL、云存档、平台 SDK、真实支付或抖音小游戏能力；战败面板中的“付费复生”仅为内测交互模拟，不会发生真实扣费。

---

## 当前可玩内容

- **双章节连续推进**：顺序推进 `1-01` 至 `2-10`；第一章含 `1-06` 精英「荒原石甲兽」、`1-09` 章节 Boss「寻木青雀」；第二章「灵木妖林」含 `2-06` 精英「玄藤鹿灵」、`2-09` 章节 Boss「碧瞳树蛟」与 `2-10` 章节结算。已通关节点可重复挑战。
- **单角色守线战斗**：万剑真君可在战场下半区域移动，支持鼠标/触屏拖动与方向键 / WASD；自动御剑初始为 1 柄青霄飞剑，攻击间隔为 0.85 秒，并拥有独立 HP。
- **近战躲避、护阵重构与复生**：普通妖物以护宗大阵为最终目标；靠近主角后暂停推进并近战攻击，拉开距离后继续攻阵。主角战败后会原地观战，妖物不再攻击 0 HP 主角。护阵受袭停止 `2.4` 秒后以 `20 HP/秒` 缓慢修复；护阵归零时不立即结束（主角存活前提），敌人停止攻阵约 `5` 秒后以 `160 HP/秒` 快速重构。复生资格只看护阵**当前** HP：护阵 HP 大于 0 即可复生，归零时暂停，重构后恢复。每局提供 1 次免费复生；之后可用不限次数的“付费复生”内测模拟（未接真实支付）。主角观战中护阵被打到 0，或护阵归零后主角死亡，才判定失败。灵石、材料和装备掉落进入主角吸附范围后会自动拾取。
- **精英与 Boss**：石甲兽会召唤碎石妖鼠；玄藤鹿灵会轻量召唤妖藤小灵。Boss 固守首领区域，以近战压制主角、远程妖术同时攻击主角与护阵；仅在护阵击破后向前压进。寻木青雀在首次结契时提供 100% 成功的教学抓捕；碧瞳树蛟以斩灭妖核、取得封印线索收束本章，暂不提前接入第二御兽体系。
- **固定装备闭环**：通过首通获得荒原护腕、守阵法衣、温灵玉佩、石甲镇符、灵木法衣、玄藤护腕等固定法器；可在「法宝」页穿戴/卸下，实际影响伤害、护阵上限或灵石结算。
- **御兽协战与培养**：首通章节 Boss 后获得并默认出战寻木青雀，可使用「青翎回风」造成范围伤害与迟缓；消耗灵石和青雀灵羽可培养至 Lv.5。
- **首页信息架构**：首页以玩家资料、灵石与仅展示的仙玉、章节场景与副本入口为首屏重点；“仙坊、灵宠、妖隙、剑域、宗门”统一作为底部主导航，活动与福利采用左侧收纳入口；任务、好友、邮件采用右侧收纳入口。灵宠页取消独立顶部标题栏，进入后直接展示当前出战内容，镇妖葫芦数量收纳在该内容区；底部同步使用“仙坊、灵宠、妖隙、剑域、宗门”五项主导航，不再保留旧三项返回导航。其中灵宠页点击“妖隙”仅返回首页，副本选择需由玩家自行打开。仙坊、剑域、宗门和活动内容当前仅提供可关闭的筹备提示，不接入商城、支付或新存档逻辑。
- **本地存档兼容**：进度、装备、材料、御兽及章节结算保存在浏览器本地；旧版 P0/P1.1 / 第一章 P1 存档会自动迁移到 schema 6 的多章节结构。

## 本地启动

### 环境要求

- Node.js 18 或更高版本
- Chromium 内核浏览器（Chrome / Edge 等）

### 启动步骤

```powershell
node .\server\start_server.js
```

随后在浏览器打开：

```text
http://127.0.0.1:3000/
```

> 项目无需执行 `npm install`；本地服务仅用于提供静态试玩文件。

## 操作说明

| 操作 | 方式 |
|---|---|
| 进入副本 | 首页选择已解锁关卡后点击「进入试炼」 |
| 移动主角 | 战斗画布内拖动；或使用方向键 / WASD |
| 暂停战斗 | 战斗页右上角暂停按钮 |
| Boss 抓捕 | Boss 虚弱后点击镇妖符或镇妖葫芦 |
| 释放御兽协战 | 获得寻木青雀后，在战斗底部点击「青翎回风」 |
| 祭炼飞剑 | 洞府底部进入「法宝」后点击祭炼 |
| 穿戴法器 | 「法宝」页的「已获法器」中点击「穿戴」；再次点击可卸下 |
| 培养御兽 | 「灵宠」页消耗 180 灵石和 1 青雀灵羽点击「培养御兽」 |
| 规避近战 / 妖术 | 保持与普通妖物的距离；Boss 妖术会分别锁定主角当前位置与护阵，可通过移动规避主角目标的妖术 |
| 战败后复生 | 护阵当前 HP 大于 0 时，点击「免费复生」（每局 1 次）或「付费复生」（内测模拟、不限次数）；护阵为 0 时等待约 5 秒静默后的快速重构 |

## 自动检查

在项目根目录执行：

```powershell
node --check .\p0.js
node --check .\p1-data.js
node .\tests\test.js
```

`tests/test.js` 会按固定顺序执行七项独立检查，并在全部成功后汇总结果。若需定位某一类问题，可直接单独运行对应检查文件。
