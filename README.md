# 修仙御兽：万剑封妖

> **开发阶段：P0 可玩原型开发中**
> **当前副本：第一章「幽冥荒原」普通试炼**
> **最后更新：2026 年 9 月 9 日**

《修仙御兽：万剑封妖》是一款国风修仙、御兽收服与万剑镇妖题材的轻量战斗游戏原型。玩家扮演天衍剑宗末代宗主「万剑真君」，在幽冥荒原守住护宗大阵，击退妖潮、挑战并收服守关大妖「寻木青雀」。

> 本仓库当前用于验证 **P0 最小可玩闭环**。它不是正式线上版本，未接入账号、MySQL、平台 SDK、支付或抖音小游戏能力。

---

## 当前可玩内容

- **单角色守线**：万剑真君可在战场下半区域移动，支持鼠标/触屏拖动与方向键 / WASD。
- **自动御剑**：初始仅 1 柄青霄飞剑，自动锁定靠近护宗大阵的妖物；当前攻击间隔为 0.85 秒。
- **普通副本**：第一章「幽冥荒原」，共 3 波小怪，之后出现章节 Boss「寻木青雀」。
- **阵线压力**：妖物越过护宗阵线会扣除护宗大阵 HP；HP 归零则本局失败结算。
- **掉落与拾取**：小怪/Boss 掉落仙石和法器，进入 380 范围内会自动吸附至主角。
- **Boss 抉择**：Boss 弱化后可选择抓捕；抓捕失败时 Boss 狂暴、回血、加速，玩家仍可击杀补救。
- **局外最小成长**：仙石祭炼飞剑、法器展示、寻木青雀展示，以及浏览器本地存档。

## 本地启动

### 环境要求

- Node.js 18 或更高版本
- Chromium 内核浏览器（Chrome / Edge 等）

### 启动步骤

```powershell
node .\server\start_server.js
```

随后在浏览器打开：

```text
http://127.0.0.1:3000/
```

> 本项目目前不依赖 `npm install`；本地服务仅提供静态试玩文件。

## 操作说明

| 操作 | 方式 |
|---|---|
| 进入副本 | 首页点击「踏入荒原」 |
| 移动主角 | 战斗画布内拖动；或使用方向键 / WASD |
| 暂停战斗 | 战斗页右上角暂停按钮 |
| Boss 抓捕 | Boss 虚弱后点击镇妖符或镇妖葫芦 |
| 祭炼飞剑 | 洞府底部进入「法宝」后点击祭炼 |

## P0 范围边界

当前 P0 不做以下内容：

- 多角色、多职业、多宠物出战与宠物技能；
- 第二章及以上副本、深渊/团本、排行榜；
- 装备打造、复杂词条、交易、商城、抽卡、公会；
- MySQL 联调、账号体系、抖音小游戏部署、线上运营功能。

## 当前验证状态

当前版本已具备基础战斗、移动、自动御剑、掉落吸附、Boss 抓捕与本地存档代码。P0 仍需完成普通斩妖、抓捕成功、抓捕失败后击杀补救、护阵失守四条结局的完整回归验收后，才能标记为 P0 可交付试玩版本。
